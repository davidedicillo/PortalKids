Open-source routine board for Meta Portal

PortalKids

I built this for our kitchen Portal so my kids can see routines, tap off tasks, earn points, and trade them for parent-approved prizes. A few parents asked for it, so this is the simplest installer path I have so far.

Download Mac installer View source

Early build. Free, home-network focused, and not an App Store app.

Beginner path

Install from a Mac over USB

The installer includes the Android tools, the PortalKids app, and the optional Mac hub. You do not need Android Studio or Java installed.

  1. 1
    Enable USB debugging

    Turn on developer options on the Portal, then allow USB debugging.

  2. 2
    Connect the Portal

    Plug it into the Mac with USB and wait for the installer to show it is ready.

  3. 3
    Click install

    The Portal app starts standalone. The Mac hub is optional for always-on admin and backups.

What it does

Kid-facing board

Large task tiles, visual cues, two-child layout, point counters, and simple tap-to-complete behavior.

Parent admin

Edit children, routine windows, draggable task order, icons, colors, and reset times from a local web page.

Wallets and rewards

Points accumulate in child wallets, and kids can redeem shared real-world rewards priced by a parent.

Standalone first

The Portal can run by itself. An always-on Mac hub is available if you want central admin or multiple Portals later.

A few honest notes

  • This is a personal open-source project, not a commercial product or paid service.
  • The current Mac installer is ad-hoc signed. If macOS blocks it, right-click the app and choose Open.
  • It is meant for home networks. There is no cloud account or remote access service.
  • If something breaks, open an issue on GitHub with the Portal model, macOS version, and what the installer showed.
